# Prime Physio Performance & Rehabilitation

Starter website built as a responsive static site.

## Replace before publishing
- `YOUR-EMAIL@example.com`
- Qualification, registration and experience placeholders
- `primephys.png` contains the supplied company logo
- Privacy / terms / clinical disclaimer links
- Any service wording that doesn't precisely match your qualifications and scope

## Free publishing
Upload `index.html`, `styles.css` and `script.js` to a GitHub repository and enable GitHub Pages under Settings → Pages. This gives you a free `github.io` address.

For a production enquiry/booking workflow, connect the form and booking button to a suitable service or backend.
